# Drop your product photos here

Upload your original product image files into **this folder** on the
`claude/festive-clarke-JjqNg` branch (GitHub → *Add file* → *Upload files*),
then tell me you're done.

I'll run the optimizer (`npm run optimize:images`), which resizes and
compresses each one into a fast WebP under `public/products/`, and wires them
into the catalog. Originals here are ignored by the build.

Any filenames are fine — I'll sort them alphabetically and map them in order.
